# Iris Dataset – K-Means Clustering

## About the Project
This project uses the Iris dataset to explore K-Means Clustering and predict flower species using a Flask web application.

## Features
- K-Means Clustering using Machine Learning
- Iris flower species prediction using KNN
- Dataset preview and species count
- Simple Flask web interface

## Technologies Used
- Python
- Flask
- Pandas, NumPy
- Scikit-learn
- Jupyter Notebook
- HTML, CSS

## Dataset
The Iris dataset contains four features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## How to Run

**1. Install required libraries**
```bash
python -m pip install flask pandas numpy scikit-learn matplotlib seaborn scipy notebook
```

**2. Run the application**
```bash
python "app 3.py"
```

**3. Open in your browser**
```text
http://127.0.0.1:5000
```
